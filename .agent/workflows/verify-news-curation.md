---
description: Verify News Curation in Flutter App
---

1.  Run the Flutter app.
2.  Navigate to the "Feed" tab (Social Feed).
3.  Observe the news items listed.
4.  Verify that all displayed news items have a date within the last 48 hours.
5.  (Optional) If you have access to the debug console, check for any "Social Fetch Error" logs which might indicate parsing issues, though the code has a fallback.
