## 🚀 Quick Start Instructions

### Step 1: Setup Supabase (2 minutes)
```
1. Create account at supabase.com
2. Create new project
3. Copy Project URL and API Key from Settings > API
```

### Step 2: Initialize Database (2 minutes)
```
1. Open Supabase SQL Editor
2. Paste contents of database-setup.sql
3. Execute query
4. Tables are created with sample data!
```

### Step 3: Configure Dashboard (1 minute)
```
1. Open index.html in browser
2. Click ⚙️ Settings
3. Paste Supabase URL and API Key
4. Click Save
5. Data loads automatically!
```

**Total Setup Time: 5 minutes!**
